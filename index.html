System Architecture Notice

This middleware executes entirely within your browser utilizing IndexedDB for high-performance, persistent data storage. It is engineered to handle massive M3U or Xtream payloads without transmitting your private upstream credentials to an external server.

Import M3U Playlist

Upload a local .m3u file or paste a provider URL. The inline worker will parse the metadata structure automatically.

OR

Xtream Codes Integration

Connect directly to an Xtream API. Note: Due to browser security constraints, the target server must support CORS, or you must use a local CORS proxy.

To connect directly from your browser, you must install a browser extension like "Allow CORS" and enable it. This allows your browser to act exactly like a native IPTV player.

Google Drive Hosting Instructions

  1. Download your playlist.m3u and (if applicable) guide.xml files using the buttons above.
  2. Upload both files to your Google Drive.
  3. Right-click each file in Drive, select "Share", and change access to "Anyone with the link".
  4. Copy the file link. It looks like: https://drive.google.com/file/d/YOUR_FILE_ID/view?usp=sharing
  5. Convert the link to a direct download format for your media player apps:
    https://drive.google.com/uc?export=download&id=YOUR_FILE_ID
